# Basic-Calculator
A Basic Calculator built using HTML, CSS, and JavaScript. This project performs standard arithmetic operations and includes additional features like square root, percentage calculation, and memory functions (M+, M-, MR, MC). It's a great hands-on project to strengthen front-end development skills and understand DOM manipulation.
